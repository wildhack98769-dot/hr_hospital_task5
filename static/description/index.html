Hospital Management

An Odoo module for hospital workflows: patients, doctors, visits, disease classification, reporting and access control.

Features

  • Patient and doctor cards with medical details.
  • Visit management with status flow and history.
  • Disease classifier with hierarchical groups.
  • Kanban views for the main hospital objects.
  • Printed PDF reports for doctor and disease analytics.
  • Ukrainian localization.

Access model

  • Patient
  • Intern
  • Doctor
  • Manager
  • Administrator
